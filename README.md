### Installasi & Setup
> [!NOTE]
> pra-syarat: nodejs v24.16, yarn v1.22

#### Clone project
```bash
git clone https://github.com/dimasyoga42/Elaina-MD
cd Elaina-MD
```
#### install peckage keseluruhan
```bash
yarn install
```
copy env.exemple
```bash
cp .env.example .env
```
